# The picture that tastes of one ingredient

One ripe strawberry, macro and glossy, filling the frame against a dark,
moody background. A single ingredient, made to look delicious at first
glance: radial light from the upper left, deep crimson shading, golden
seeds in curving rows, a fresh green calyx, soft specular gloss and a few
water droplets.

## Run

```sh
python3 build_image.py   # regenerates entry.png (1024x1024)
python3 main.py          # copies entry.png to $MAKEFUN_OUTPUT_DIR (default /output)
```

Built fully procedurally with numpy + Pillow. No external assets, no network.
